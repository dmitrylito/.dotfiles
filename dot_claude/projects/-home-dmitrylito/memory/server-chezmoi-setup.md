Host `dlco` is a bare-metal Arch server (2 GPUs: RTX 5060 Ti 16G + RTX 3060 12G; whisperx uses GPU): Docker host for fleetchaser/cer/billingapp + nginx-proxy-manager, Podman host for the media stack (gluetun VPN + qbittorrent), Samba (intentionally kept even with no shares yet), Tailscale, Cockpit, CUPS for a Zebra label printer.

**`~/SERVER.md` is the canonical operational reference** (created 2026-07-04): compose stacks + ports, nightly DB refresh, ZFS, storage map, cleanup runbook. `~/CLAUDE.md` points to it. Two ZFS pools: `data` (21.8T, `/data/media`) and `scratch` (928G, `/scratch/downloads`, qbittorrent). ⚠️ `data` is a **stripe of 2 disks with NO redundancy** — single disk failure loses the pool; no snapshots or scrub automation. Nightly cron `0 3 * * * ~/import_db.sh` refreshes the fleetchaser DB from GCS and writes a ~133G `docker-volume-snapshot` to `~/Projects/tmp/docker/fleetchaser_db_volume` (regenerated nightly — not cruft). 2026-07-04 cleanup reclaimed ~107G (docker build cache, caches, trash, stray IDE-server/mac leftovers).

Dotfiles/packages are managed by chezmoi (`~/.local/share/chezmoi`, profile `server` in `~/.config/chezmoi/chezmoi.toml`) driving `playbook.yml` via `run_onchange_executable_install-packages.sh.tmpl`. Server packages live in `packages-server-pacman.txt` / `packages-server-aur.txt`, regenerated by `scripts/update_server_package_lists.sh` (refuses to run unless profile is `server`). The `packages-added-*`/`packages-drivers.txt` lists are for the Omarchy desktop profile only.

**Why:** before June 2026 the server's packages were untracked; audit trimmed 726→~500 packages and made the set reproducible.

**How to apply:** after installing/removing packages on the server, re-run the update script and commit the chezmoi repo. Related: [[tooling-preferences]].
