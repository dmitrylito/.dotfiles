# Dmitry's Dotfiles

These dotfiles are managed using [Chezmoi](https://chezmoi.io/).

## 🚀 Quick Start (Fresh Install)

To bootstrap a new machine (e.g., a fresh Omarchy installation, a Mac, or a server), run this single command:

```bash
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply dmitrylito
```

During initialization, Chezmoi will prompt you:
`Machine profile (Omarchy, server, mac):`

*   **Omarchy:** Installs everything, including desktop-specific configurations like Hyprland, Waybar, SwayNC, and Ghostty.
*   **server / mac:** Installs only terminal essentials (Zsh, Neovim, Tmux, Lazygit, Yazi).

## 🛠️ Daily Workflow

Your home directory files (e.g., `~/.zshrc`) are now generated by Chezmoi. **Do not edit them directly.**

Instead, use the custom `ce` (Chezmoi Edit) alias provided in the Zsh config:

```bash
# Edit any managed file
ce ~/.zshrc
ce ~/.config/nvim/init.lua
```

**What `ce` does:**
1. Opens the source file in `~/.local/share/chezmoi` in your editor.
2. Automatically applies the changes to your home directory when you save and exit.
3. Automatically commits and pushes the changes to this GitHub repository.

## ⚙️ Managing Chezmoi Itself

To change the machine profile or adjust Chezmoi settings on a specific machine:
```bash
chezmoi edit-config
```

To add a new file to be managed by Chezmoi:
```bash
chezmoi add ~/.config/some-new-app/config.conf
```
